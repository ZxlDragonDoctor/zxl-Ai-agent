- 当前运行中的主应用仍为上一课，尚未接上新的 `/auth/status`，因此认证栏明确显示 `NOT_FOUND`；静态知识入口可阅读。**这不是登录成功证据**，正式业务页面不能在这一状态下通过本课验收。
