# 第 21 课运行超时验收

在正式多 Agent 工作台提交一条知识查询，将预算设为 1 秒。后端使用真实 PostgreSQL 和正式运行配置。

| 操作 | 实际结果 | 截图 |
| --- | --- | --- |
| 展开运行事件 | 流式订阅成功，页面展示持久事件 | [打开订阅](02-stream-open.png) |
| 等待同步终态 | 页面展示运行失败，事件接口返回 `RUN_DEADLINE_EXCEEDED`，事件号连续 | [终态](05-synced.png) |
| 请求后续事件 | 已到终态，接口返回空列表，页面没有重复事件 | [补读](06-manual-no-duplicates.png) |
| 切换英语 | 同一运行及其终态仍可查看 | [英文](07-english.png) |
| 打开第 21 课阅读卡 | 图谱展示这一批的验收范围与课程入口 | [阅读卡](08-learning-graph.png) |

该短预算用例验证工作流超时和终态交付。模型或 MCP 是否实际收到请求取决于预算在何处耗尽。
