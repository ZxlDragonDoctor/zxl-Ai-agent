首轮浏览器检查发现归档的发送按钮已锁定，输入框仍可输入。修复后重跑对话流程，分别断言输入、发送和删除禁用。测试未点击删除任何实际用户数据；删除拒绝用合成记录的正式 HTTP 请求验证。普通新会话验证创建和可编辑状态，未为此次归档验收调用模型。

- Java 13 类 77 项，0 失败、0 跳过，其中 24 项连接真实 PG。覆盖有界文件读取、并发导入、归属冲突及回滚、正式会话和知识授权回归。日志 `target/lesson17-archive-final-tests-20261107.log`。
- CLI 先 `IMPORTED`，真实 PG 进程重启后同一清单 `ALREADY_IMPORTED`。实际 HTTP 导入前 2 项、导入后 14 项、重启后 12 项（复验有重叠）。覆盖未归属隐藏、本人读取、跨租户 404、续聊/删除/预演/记忆拒绝、旧运行未注册、源与备份摘要一致、篡改拒绝和恢复原字节后可读。复验未使用内存数据库。
