# 第 21 课首批可观测性验收

Chrome 使用生产前端访问正式工作台。提交知识检索运行并展开事件区，从界面读取运行 ID，再以该 ID 查询专用后端日志。

| 操作 | 观察结果 | 截图 |
| --- | --- | --- |
| 提交运行，展开事件区 | 页面显示运行 ID 和已保存事件。用该 ID 找到模型容量等待、模型首帧以及 MCP 工具完成日志 | [运行中](02-stream-open.png) |
| 等待结束 | Chrome 收齐事件，最终结果包含知识引用 | [终态](05-synced.png) |
| 点击读取后续事件 | 数据库接口返回空列表，界面事件没有重复 | [补读](06-manual-no-duplicates.png) |
| 切换语言 | 保留终态，状态文字切换为英文 | [英文](07-english.png) |
| 打开第 21 课阅读卡 | 展示工程状态和课程文档入口 | [知识图谱](08-learning-graph.png) |

同一真实运行的规划调用等待许可 10 ms，许可持有 13913 ms，首帧 916 ms。检索任务的模型首帧 290 ms，对应 MCP 工具耗时 6987 ms。31 项后端回归覆盖模型执行、授权和工具日志。完整失败链路和遥测导出留待后续验收。
