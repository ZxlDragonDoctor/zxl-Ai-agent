# 第三课统一工具结果与结束原因实施计划

**目标：** 完成已确定的第三课任务二、三、四，所有本地工具共用结果契约，MCP 结果通过边界适配归一，页面显示真实结束原因；集中验收并提供第四课。

**方案：** `ToolResult<T>` 提供 success/code/message/data，各 Java 工具直接返回该类型；注册器给远程 MCP 回调加结果适配，保留原始数据。Agent 保持已有状态枚举，单独保存结束原因；终态 SSE 兼容现有事件类型并增加 endReason。前端接收并格式化契约，保留实时思考和部分结果。

**技术：** Java 17、Spring AI M6 工具回调、Spring MVC SSE、Vue 3 / TypeScript。

现有课程已明确设计，用户已要求直接实现全部三项任务；按完整功能单元推进。

## 验收边界

- 有效、无效预算；最后一步完成；工具失败后模型解释；终止工具；模型与工具异常；失败时保留已完成记录。
- 本地工具必须返回统一对象，错误结果也回填；MCP 适配保留结构化错误和原始 payload，不能将未知外部结果一律视为成功。
- 外部搜索、下载、PDF 字体、图片文件和终端依赖单独注明验证范围；使用临时目录、本地 HTTP 服务和受控命令进行可重复检查，避免产生未授权业务副作用。
- 仓库现存未提交 Agent 实时流程与任务一属于本次功能必需依赖，随功能提交；无关多 Agent、记忆与配置改动继续留在工作区。
