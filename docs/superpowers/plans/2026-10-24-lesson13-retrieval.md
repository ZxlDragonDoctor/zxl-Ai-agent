# 第十三课实现计划

**目标：** 按已发布且用户要求实施的六单元任务包，在真实 PG 知识库中交付可解释检索与固定集评测，并发布第十四课。既有任务包是本批范围依据。

**结构：** 保留第十二课文档写入与精确检索。新增 retrieval 包负责截止时间、关键词、RRF、可替换重排、改写与最终有效性检查；服务端固定教学租户。前端在 `/knowledge` 增加检索实验室。中文关键词采用明确标注的应用切词加参数化子串基线，不冒充 BM25。规则重排与可选真实 HTTP 重排区分展示。

## 任务与验收

- [ ] 检索契约与纯算法：先编写 RRF 去重/手算、非法重排输出、指标、预算测试；失败后实现。文件位于 `knowledge/retrieval` 与对应测试目录。
- [ ] PG 通道及服务：向量/关键词/混合模式，原问题保留，可选一次词汇补充改写；每路最多20、TopK最多5。统一截止时间传到SQL/HTTP；单路与重排故障显式降级、全失败显式错误。发送候选前及返回前检查租户/active/model空间。真实PG测试不得skip。
- [ ] 固定集：至少20问、调参与留出组、0/1/2标签和禁止块、资料/块快照绑定与校验。计算Recall/MRR/nDCG/no-answer分组和实测耗时，不预设重排一定提升。真实模型结果单独报告。
- [ ] 前端：复用知识库样式，模式/改写/重排/TopK/预算、实际通道解释、候选来源、降级、指标对照和导出；每个控件与错误状态逐项截图。
- [ ] 第十四课：引用、证据不足拒答与长期记忆完整任务包；同步双语图谱及路线，个人掌握不变。
- [ ] 回归：本课与11/12相关后端测试，前端测试与生产构建，图谱ID/端点/先修DAG校验；真实浏览器复查筛选、关系、阅读与双语。
- [ ] 逐职责选择性暂存、提交并推送，核对远程；保留用户未完成改动及本地配置。

## 协作边界

后端子Agent负责检索与PG/API；评测子Agent负责固定集与指标（通过后端接口接线）；课程子Agent负责14课及图谱；主Agent负责前端、整合、真实运行与截图、审查及Git。API字段先以共享契约沟通并固定，不同时修改同一文件。Git操作由主Agent串行执行。

## 明确边界

固定演示身份不代表生产认证。精确扫描不代表ANN性能优化。应用分词子串基线不代表完善中文全文引擎；规则重排不代表模型排序。未执行的真实服务/质量实验必须明确保留未验收状态。截图只证明本机当前交互，不承诺无限组合无缺陷。
