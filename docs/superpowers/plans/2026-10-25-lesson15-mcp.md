# 第十五课 MCP 工程实践实施计划

> For agentic workers: use subagent-driven-development; 根 Agent 统一执行 Maven、提交和推送，避免共享构建目录冲突。

**Goal:** 让研究 Agent 通过真实 MCP 只读工具访问当前有效的 PG 知识，提供可观察、可停止、有界的执行链，并发布第十六课。

**Architecture:** 复用第十三课检索与第十四课证据边界。MCP 协议运行时负责连接、发现与资源所有权；契约适配器负责不可信参数和远程结果；研究执行层只注入允许的工具。统一会话展示实际工具事件与发现状态。

**Tech Stack:** Java 17 / Spring Boot 3.4.6 / Spring AI M6，沿用已解析的 MCP SDK，PostgreSQL 16 + pgvector，Vue 3。

## 已批准范围

以 `docs/learning/15-mcp-tool-contracts-and-adapters.md` 六个单元为实施与验收依据；用户本次要求继续实施。固定演示身份，生产登录授权留在第十七课；不引入实际写操作。

## 执行与提交顺序

- [ ] 检查依赖和既有适配器；记录工作区基线，保留用户改动。
- [ ] 契约失败用例 → 严格输入、协议错误优先、输出限制 → 专项测试；独立提交。
- [ ] 运行时失败用例 → 实际 MCP 服务和有界客户端 → 真实 PG/连接生命周期测试；独立提交。
- [ ] 研究 Agent 失败用例 → 模型工具选择与执行、可信工具白名单、统一 Provider 与公开事件 → 回归；独立提交。
- [ ] 发现状态和刷新入口、双语及工具明细；前端测试和构建；独立提交。
- [ ] 实际 MCP、PG、真实模型及逐状态页面截图；记录失败和重试，不以测试替代页面验收。
- [ ] 第十五课实现记录、第十六课完整任务包和知识图谱；构建、图谱校验及页面验收；按文档职责提交。
- [ ] 检查差异、推送并核对远程 SHA；最终报告证据和未覆盖边界。

## 文件职责

- `knowledge/mcp/`：固定只读工具、协议服务、客户端生命周期及预算。
- `tools/support/StructuredMcpToolCallback.java`：现有适配边界的严格校验与结果处理。
- `multiagent/agents/ResearchAgent.java`、`conversation/agent/`：实际研究工具执行和统一会话注册。
- 前端 `components/` 与 `api/`：发现状态、刷新与真实结果展示，沿用现有页面样式。
- `docs/learning/`、图谱 `catalogue.json`：课程、证据和关系；不写个人掌握状态。

## 验证边界

分别记录离线单元测试、实际 MCP 传输、真实 PG、模型工具选择、页面截图。取消只说明本地停止与尝试取消传输，不声称远程回滚。远程响应限制若发生于 SDK 反序列化后，明确记录无法阻止此前分配内存。
