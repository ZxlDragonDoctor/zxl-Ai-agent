# 第十七课：旧历史受控归档实施计划

> 使用测试驱动与子 Agent 按职责实现；当前用户已授权连续完成课程，不重复请求例行实施许可。

**目标：** 让明确选择的旧JSON会话经离线校验/备份/PG归属登记后，能在统一对话页面只读查看；原文件、现有用户数据和个人学习状态保持不变。

**设计：** 复用现有FileConversationRepository和PG resource_owner。离线入口读取显式清单（规范UUID、SHA256、目标tenant/subject），拒绝自动扫描认领、覆盖已有归属和任意路径；读取有界、严格JSON、拒绝符号链接。备份完成并核验源摘要后，单个PG事务写导入receipt与owner，幂等重放必须匹配全部清单。部分文件备份失败不得写owner。数据库不可用不得回退。

导入资源为只读归档：legacy_import_id标识使写权限拒绝；会话读取校验同一份bytes的摘要，不恢复旧running、不执行旧工具、不改原文；返回readOnly=true、busy=false。页面支持打开归档和查看历史，清楚显示只读，不允许发送或删除。普通新会话保持原行为。历史运行只作为归档内容，不恢复执行器或创建活跃run。

目标账号由既有离线ProvisionAccountCommand预先创建，密码不走命令行。实际用户旧数据仍需运维明确选择映射；本批以合成资料验证真实PG与页面，不擅自给真实旧文件授权。

## 步骤与责任

- [x] 子Agent：检查迁移版本、锁序/事务、仓储读取与测试接线，细化receipt和幂等契约。
- [x] 子Agent：先红后绿实现归档清单、路径/摘要/备份验证、PG原子登记及离线CLI；单元与真实PG测试，测试夹具在各测试结束时清理。
- [x] 主Agent：接正式会话读取、只读写策略与摘要校验，先补失败用例；相关会话/授权回归。
- [x] 前端子Agent：统一会话中readOnly呈现与发送/删除阻止，双语；必要前端行为测试与生产构建。
- [x] 主Agent：实际合成旧历史导入、真实PG重启/幂等/外人不可见；页面登录、列表、打开、切换、只读、普通新会话对照和截图。只读迁移不调用模型，真实模型证据复用上一批、不能伪称本批新调用。
- [x] 主Agent：图谱/课程/边界同步；在独立浏览器对合成进度导出→恢复→深比较，实际个人进度不改动。
- 主Agent：逐职责提交并推送，最终核对以远端分支 SHA 为准。

## 验收不变量

1. manifest不匹配、文件更改/损坏、路径逃逸、重复ID、备份失败、目标失效、归属冲突时零新增owner。
2. 同清单幂等；不同摘要或目标不能覆盖；并发导入最多一份归属和receipt。
3. 目标可读、其他主体/租户不可见；归档写入/删除/续聊服务器拒绝，UI只读。
4. 旧running不触发恢复或工具调用；导入及读取后源SHA不变；内容更改后读取拒绝。
5. DB重启后receipt/归属仍在，内存不是权威；真实旧文件不自动归属，凭据/原文/运行数据不入Git。
