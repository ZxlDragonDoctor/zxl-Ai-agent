# 第五课实施计划

目标：完成已发布的[第五课六项任务](../../learning/05-plans-tasks-and-dataflow.md)，并基于实际代码发布第六课。用户已要求直接实现，沿用课程契约，不重复征询范围。

## 设计

- `multiagent/planning`：TaskDefinition、严格 JSON 解析、两阶段依赖转换、纯 Java DAG 校验；拒绝隐式默认计划。
- `multiagent/execution`：稳定错误码、不可变输入快照、直接依赖结果和统一 Prompt 渲染。
- Orchestrator：规划与校验纳入整体失败路径，能力确定匹配；每轮同一工作实例最多领取一个任务，不通过伪造依赖实现串行；跨计划忙碌明确报错。
- 工作角色：消费真实 executionContext，Supervisor 保留旧整体汇总路径；记录应用发起的模型调用数。
- Controller / 页面：结构化错误、真实任务与输入报告，使用执行报告替换随机进度，不新增工作 Agent 页面。
- 已有多 Agent 初始化、空计划和失败传播修改作为独立前置提交收录，其他已有改动与本地配置保留。

## 构建与证据

本轮未明确要求新增或运行自动测试，使用 `mvn -q -DskipTests compile` 与 `npm run build`；真实模型页面观察与静态审查单独记录，不能声称覆盖全部故障 / 并发案例。原课程中的集中验收矩阵继续作为后续专项用例目标。

第六课围绕现有生命周期缺口设计：状态迁移统一、终态不可回退、失败因果与 BLOCKED、同步异常清理、结果汇总不掩盖失败。取消和完整并发配额仍留第七课，幂等重试留第八课。
