# 第六课实施计划

目标：完成已发布的第六课六项任务，并发布第七课任务包。用户已要求直接实施既定课程方案，沿用当前工作区，保留无关修改。

## 方案

- `TaskSnapshot` 保存状态、产物、失败、执行者、调用数与时间；`TaskLifecycle` 是唯一 CAS 写入边界，终态不可改写。
- `AbstractBaseAgent` 将同步异常、失败 Future、null Future、空产物和成功交给同一完成函数；完成底层调用后释放本次占用，事件异常不影响清理，关闭状态不回退。
- `FailurePropagation` 先沿失败依赖传播 BLOCKED，再将无关未启动任务按 PLAN_ABORTED 阻塞；已经启动的同轮分支等待收敛。
- `WorkflowRun` 只决定一次 `WorkflowOutcome`，冻结任务与统计；HTTP / SSE 复用该结果，规划失败允许 planId 为空，额外汇总有独立快照。
- 现有页面显示失败根因、阻塞来源、结束时间和汇总状态；终态后拒绝后续运行报告，不新增 Agent 页面。
- 任务六明确包含集中验收：只新增并运行本课可控替身的专项用例，不运行依赖真实模型的全套测试；正常业务另做真实页面演示。
