# 第十一课：上下文工程实施计划

> 执行方式：按 subagent-driven-development 分工，后端实现与测试由子 Agent 负责，主 Agent 复核、维护知识图谱、运行回归并提交推送。

**目标：** 为统一会话提供有预算、可追溯的历史组装，发布第十二课知识接入任务包。

**设计：** 原始 JSON 会话是历史来源；模型上下文是每次计算的派生视图。完整 run 是裁剪单位，摘要采用带来源的原文摘录，不引入摘要模型。系统提示与当前用户输入优先，预算不足明确失败；预算使用可替换的估算器，不能声称与供应商计费 token 一致。

**技术栈：** Java 17、当前 Spring AI M6 依赖、JUnit/MockMvc；现有 Vue 图谱目录。

## 方案选择

- 只保留最近 N 轮：复用简单，但不能限制单轮大小或解释信息丢失。
- 确定性预算与可追溯摘录（本次采用）：离线可测，保留原文与角色边界，可观察取舍。
- 模型生成摘要：压缩灵活，但增加费用、幻觉与摘要评估工作，作为后续扩展，不伪称已完成。
