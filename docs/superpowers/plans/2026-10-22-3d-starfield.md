# 3D 星空图谱实施计划

**Goal:** 将用户确认的 3D 星空网络设为默认学习图谱，支持持续动态、旋转和聚焦。

**Architecture:** 3dGraphModel.ts 负责不可变数据适配和相机坐标；KnowledgeGraph3D.vue 管理 Three.js 场景、交互与资源；LearningGraph.vue 按需加载并提供 2D 回退。

**Tech Stack:** Vue 3、3d-force-graph、Three.js、Node 内置测试。

- [x] 锁定 3D 依赖并检查类型与生命周期 API。
- [x] 实现节点副本、连接数和相机聚焦纯函数，检查不变性与退化坐标。
- [x] 实现发光节点、真实关系流动粒子、星空、自动环绕、悬停高亮、聚焦、暂停和资源释放。
- [x] 默认 3D 全图，接入阅读、筛选、2D 切换、错误回退和减少动态模式。
- [x] 6 项 Node 检查、Vue 类型检查及生产构建通过；知识库新增三维原理和操作指南。依赖、数据/相机、渲染组件、入口和内容按职责提交并推送。

验证边界：开发服务监听 5174。此前浏览器策略拒绝本机页面访问，本次未绕过；真实 WebGL 旋转、镜头、帧率和画面一致性未记为已验收。GPU 资源检查来自代码审阅，不是长时间浏览器内存测量。
