# 第九课持久化与恢复实施计划

**目标：** 完成可运行的持久化工单任务，发布第十课 Temporal 学习任务，同步图谱与证据。

**架构：** Java 17 JDBC 短事务；显式迁移与六张业务表；默认文件型 H2，允许 PostgreSQL URL。`lesson9-demo` 开启独立演示 API 和有界 worker，不替换现有多 Agent 编排的内存权威。操作、工单、任务完成和事件在同库事务内提交；版本、租约与递增令牌阻止竞争和迟到提交。

## 不变量

1. 同一业务操作 ID 不能通过换 run ID 绕过去重；持久化指纹并核对参数。
2. 领取/续租/完成必须核对运行状态、原截止、当前 owner/token/lease；DB 时间作为租约判断依据。
3. 终态不可反转；旧 attempt 保留历史；恢复扫描不得重复创建 attempt。
4. 同库副作用与操作结果原子提交，远程 I/O 不放在事务内；不宣称跨系统 exactly-once。
5. 查询从数据库读取，不以 JVM 未找到 Future 判定不存在；重启不重新给予完整预算。
6. 默认本地实验范围，无生产认证、租户授权、真实企业工单、模型恢复或容量验收声明。
