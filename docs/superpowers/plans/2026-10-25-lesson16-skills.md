# 第十六课：可版本化 Skill 与受控业务策略实施计划

> 根 Agent 使用 subagent-driven-development；Maven 串行运行，子 Agent 分别负责 skills 包、前端和第十七课任务包。

**Goal:** 在统一会话中执行固定版本的 IT 问题分析策略，提供当前证据和明确未创建的工单草稿；完整验收六单元并发布下一课。

**Architecture:** SkillDefinition/Registry 固定步骤、版本和工具来源；SkillExecutionPolicy 在模型可见、实际调度及发布前限制权限交集；SkillRunner 复用第十五课真实 MCP/ResearchRunner 与原文核验。会话事件保存当次不可变快照，版本选择只影响新运行。固定课堂身份不替代生产登录。

**Tech Stack:** Java17、Boot3.4.6、Spring AI M6、SDK0.7.0、真实 PostgreSQL+pgvector、Vue3。

## 职责与步骤

- [x] skills/契约与注册：严格解析、摘要、v1/v2、默认指针与停用；先红灯用例，再实现、独立提交。
- [x] skills/策略与执行：四层交集、四业务步骤、不可变运行快照、撤销检查、共享截止、取消与容量；单测覆盖成功和拒绝，独立提交。
- [x] research/配置暴露可复用Gateway/Model/Verifier；ConversationAgentProvider默认重载接收受限Skill选择，原Provider保持兼容；请求仅接受Skill标识版本，身份由服务器构造。集成回归后提交。
- [x] 只读Skill目录API，默认不开放在线发布/管理；用可信本地运维入口验收默认v1→v2→v1，未授权HTTP管理请求拒绝。回滚不修改旧快照。
- [x] 前端统一会话选择版本、查看范围/步骤/证据/草稿与历史版本；双语、移动、连续切换与错误状态先测后实现。
- [ ] 串行自动测试、真实MCP/PG故障恢复、真实模型成功/澄清/空/注入负例；逐状态页面截图，保留失败和重跑。个人进度前后精确恢复。
- [ ] 第十六课实现与验收、第十七课完整任务包、图谱稳定ID/证据/课程入口更新；测试、生产构建和实际图谱阅读检查。
- [ ] 按职责选择性提交、push并核对远程SHA，保留用户无关改动；继续后续课程。

## 验收边界

模型生成文本继续受引用和当前证据检查；结构化草稿由Java生成，created=false。审计快照复用会话持久事件，本课不宣称跨JVM自动续跑、生产认证、沙箱或已审批写入。外部调用/截图/自动测试分别记录，真实PG不可用不得内存替代。
