# 3D 星空知识网络

用户纠正了二维 Browser 外观方向，并明确选择：节点和细线在三维空间中分布，支持旋转、缩放、点击飞近。参考 LLM Wiki 的 3D graph 描述：https://llmwiki.cc/docs#browsing-your-wiki 。

默认打开全图的深色 3D 视图，以小型发光节点、细关系线和沿关系流动的粒子呈现网络；节点按类型着色，大小参考连接数。背景星点仅作环境，不属于知识节点，不参与关系。节点间连接仍严格来自 catalogue，不生成装饰性关系。

拖动空白处旋转，右键/触控平移，滚轮缩放；缓慢自动环绕提供持续动态感。悬停高亮真实邻居与连线，点击平滑飞近并显示摘要和阅读入口。课程目录与阅读面板沿用现有内容。提供暂停动态、适应全图、重排、2D 切换和 WebGL 不可用回退。

用 3d-force-graph/Three.js 渲染，catalogue 与本地学习状态不进入物理引擎。只传节点副本，独立维护相机和 GPU 资源。卸载、切换视图、页面不可见时停止绘制，释放监听和渲染器。减少动态模式关闭自动环绕、粒子、镜头补间，并静态预计算布局。

校验：图数据不可变及相机数学边界用 Node 检查，前端类型与生产构建；真实 WebGL 页面验收受此前本机浏览器访问策略限制，不能将构建通过当成视觉验收通过。
