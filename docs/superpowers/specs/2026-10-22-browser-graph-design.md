# Neo4j Browser 风格学习图谱

用户已选择经典 Neo4j Browser：彩色圆点、细箭头、节点环形菜单、双击展开。参照 https://neo4j.com/docs/browser/operations/result-frames/ ，以其经典图交互为目标。

画布采用白底、圆内多行文字、边界截断的细箭头与沿线正向文字。选择节点显示环形展开/固定/隐藏菜单；双击切换邻居；拖拽重新加热力布局，松手自然收敛。缩放围绕鼠标位置，提供适应视图、重新布局、全屏。课程阅读和中英文切换保留。

选择与探索范围分离，单击节点不重置邻域。已探索邻居按展开节点集合计算；收起时保留其他路径仍引用的节点。隐藏只作用于当前画布，重置恢复；固定点在布局更新中保留。减少动态模式执行静态布局，不在拖拽时重新开启持续动画。

数据仍来自版本化课程 catalogue；不连接 Neo4j 数据库。复刻范围为已选择的经典图显示与交互，不声明与任意 Neo4j 版本像素一致。

验收：前端类型检查及生产构建、邻域展开/收起和箭头几何的确定性检查。此前浏览器安全策略禁止本机页面访问，不绕过该限制；页面人工验收需如实记录边界。
