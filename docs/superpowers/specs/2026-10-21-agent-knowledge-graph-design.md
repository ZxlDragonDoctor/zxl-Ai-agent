# Agent 项目学习知识图谱

2026-10-21，用户要求将学习改成长期维护的关系图谱，前端交互类似 Neo4j，能够阅读完整内容；图谱构建知识也必须成为内容。

## 使用方式

入口 `/learning`，与协作中心、统一对话并列。中央是可缩放、拖动、聚焦相邻节点的关系网络；左侧按主题、实体类型、搜索和学习状态筛选；右侧阅读完整知识卡。图谱和列表共享选择，键盘可完成操作。阅读时间仅供参考，不限制正文。

知识卡包含概念、Spring Boot 类比、当前项目落点、实现边界、练习、自查和面试问题。先修关系、代码实现、文档证据、相关概念使用不同有向关系，点击关系可看理由。未来工程能力显式标为待建设，个人“掌握”不由代码提交自动设置。

## 数据和溯源

- `docs/learning/graph/catalogue.json` 是人工维护的知识实体与关系来源，稳定 ID 不随标题变化。
- 主题、知识点、源码、文档/证据是不同实体；先修关系校验无环，普通关联允许成环。
- 详细学习卡覆盖原 28 课主题与知识图谱自身的建模、资料整理、验证、查询、可视化和 GraphRAG 边界。已有课程原文仍可完整阅读。
- 源码定位使用仓库路径、方法名和显式来源链接；不暴露本地任意文件，不打包 application 配置或凭据。
- 运行时校验 ID 唯一、关系端点、必填内容和先修环；不使用 LLM 自动猜测关系。
- 首版结构化 JSON + 邻接表，D3 force 仅负责布局；图谱模型独立于渲染器，可导出标准节点/边 JSON。Neo4j 导入与 Cypher 作为知识内容，当前不宣称已部署图数据库。

## 学习进度

浏览器本地保存未开始/学习中/已掌握、笔记、上次阅读位置；存储版本化，未知 ID 忽略。支持导出与校验后导入，明确不跨设备自动同步。推荐下一点依据先修和个人状态，可随时自由查看完整图。

## 视觉与维护

使用深色石墨画布、青绿/蓝/橙节点类型和可读关系标签，阅读侧栏保持浅色纸张风格。避免一次把全部正文挤入画布；可以切换全图、主题与一到两跳邻域。提供等价列表、可见焦点、减少动画选项和窄屏阅读模式。

每次工程改动同步更新相关知识卡、关系和证据状态。AGENTS.md 增加维护约定。第七课收尾和图谱按职责独立提交，保留无关工作区文件；第八课通过完整知识卡与工程任务入口交付。
