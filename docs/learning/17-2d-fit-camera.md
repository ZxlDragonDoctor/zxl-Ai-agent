# 图谱实践：力布局变化时如何适应画布

2D节点会随d3-force的tick继续移动。原实现只在点击瞬间计算一次范围，随后相机用240ms插值追旧目标；节点继续扩散时可能离开旧范围，直到布局结束或再次适配才恢复。

现有 `graphFitCamera.ts` 保存明确的 all/focus 意图。每次tick按最新节点坐标计算1000×700世界坐标中的边界，直接更新相机；结束沿用同一意图。平移、滚轮/按钮缩放和拖节点立即取消跟随，避免用户刚操作又被布局抢回视角。SVG禁止原生文字选中，知识卡文字仍可选。

新增3项自动化：用真实d3模拟200个tick确认旧一次性目标会裁切、逐tick目标保持在画布内；手势取消后不再返回自动目标；focus/all切换。图谱37项测试及生产构建通过。初次构建曾因移除动画后遗留未使用函数失败，清理后重跑通过，日志 `target/lesson17-2d-fit-{red,green,build}-20261106.log`。

页面复验必须是“切入2D→立即首次适配”，不靠第二次点击通过。验收中还发现：向SVG内部发送滚轮是缩放，会主动取消自动适配；测试滚页面应避开图内，不能把人为缩放后的截图归因为力布局。最终未在适配后发送滚轮，11个节点的实际DOM边界均在SVG内，平移/缩放/拖节点保持手动相机。[页面记录](../images/lesson17-private-research-2026-11-06/README.md)。本次没有修改3D。
