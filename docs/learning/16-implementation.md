## 页面问题与失败优先修复

并发容量验收先发现工具发现竞态：Gateway 在 refresh 返回后再次读取可变目录，另一请求的 discard 可能恰好清空目录，误报 SKILL_TOOL_SNAPSHOT_CHANGED。已新增受控交换锁内返回不可变快照的 discover API，业务发现复用已验证连接，手动刷新仍可重连；调度依据受审查固定契约验证参数，避免再次读取瞬时目录。新增缺API红灯、Gateway快照/越权及真实环回SSE并发刷新回归，最终22类93项全部通过（`target/lesson16-final-93.log`）。此前模型网络失败因果类型为 SocketException，公开仅输出安全诊断；该类名不足以断言网络根因。
