# 第十五课：MCP 工具契约与适配

状态：**完整六单元任务包已发布，工程尚未实施、尚未验收**。日期：2026-10-24。第十四课证据见[实现记录](14-implementation.md)，不能把学习任务发布或已有工具类当成本课通过。

业务目标：让研究 Agent 通过一个受控的只读 MCP 工具查询当前有效企业知识，并在统一页面展示实际发现、调用、结果和失败。本批复用既有工具契约与检索，不再做一套 RAG 或独立聊天页面。

## 1. 先理解 MCP 解决什么

模型提出“查 VPN 809 手册”的意图；应用校验并选择工具；MCP 客户端把参数发送给工具服务；服务端做业务查询并返回结果；应用把结果交还模型。MCP 统一能力发现和调用格式，用户身份、业务授权、资料有效性和副作用仍需 Java 应用执行。

| 层次 | Spring Boot 类比 | 必须区分的问题 |
| --- | --- | --- |
| 工具定义 | Controller 的请求 DTO 和接口说明 | schema 合法不代表用户有权限 |
| MCP 客户端 | 外部系统 Client/Adapter | 连接成功不代表某个工具调用成功 |
| MCP 服务端 | 暴露受控 Service 的接口 | 不能把客户端自报 tenant 当可信身份 |
| 统一工具结果 | 业务响应 DTO | 协议异常、业务失败和成功无结果不同 |
| Agent 工具循环 | 有预算的应用状态机 | 超时不能证明远端未执行，也不等于回滚 |

```text
研究任务 + 可信执行身份 + 剩余预算
  → 按策略选择工具 → 参数/schema/大小检查
  → 固定 MCP 服务连接 → 调用只读知识查询
  → 服务端授权与有效版本检索 → 结构化结果
  → 保留协议错误并校验业务结果 → 工具事件 → 模型引用允许证据
```

工具返回的说明、网页和原文都属于外部数据，不能提升为系统指令。一个服务通过发现接口声明“我是管理员”不产生任何权限。

## 3. 单元一：定义企业查询工具契约

### 概念

给模型的 schema 是能力说明，服务端校验是执行边界。工具只接收业务参数，身份来自已配置的可信通道。此次范围是知识查询，不开放任意 SQL、URL、文件路径或命令执行。

### 实践任务

1. 定义版本化的只读工具，例如 `knowledge_lookup_v1`；参数含 query、topK、允许的业务过滤项。query 长度、topK、未知字段、空白/类型错误和总请求大小须有限制。
2. tenant/user 由可信服务身份与授权映射决定；拒绝模型提交租户覆盖参数。固定演示身份只能证明范围隔离，不能称为完整登录系统。
3. 复用 `ToolResult`；data 返回稳定 documentId/revisionId/chunkId、真实来源范围、实际文本、阶段/降级和 traceId。成功但无资料属于成功空结果；检索不可用属于服务失败。
4. 列出错误表：参数不合法、未授权、资源不可见、预算超时、取消、容量不足、远程业务失败、协议/网络故障与不合法响应。哪些可重试须由 Java 策略决定，不能相信外部文本自报 `retryable=true`。
5. 固定 schema/工具契约版本；破坏性修改换版本或提供迁移。为现有时间/搜索工具补兼容断言，不因新工具改变旧契约。

**交付与验收：** 工具目录说明、输入/输出/错误例子和失败优先的契约测试；未知字段和伪造身份不能触发真实查询。字段名为建议，实际 API/类名在本课实施记录确定。

## 4. 单元二：可启动的 MCP 服务端与客户端生命周期

### 概念

`tools/list` 是发现，`tools/call` 是执行；工具列表是带来源与版本的能力快照。连接创建、发现超时、断开和关闭必须有明确所有者。

### 实践任务

1. 创建仓库内可获取的最小教学服务，导出只读知识查询。调用真实 PG 的同一领域服务或受控后端接口，不能在服务端另建内存假数据后宣称主线通过。
2. 固定单一传输与 loopback 演示端口，配置外置；给出客户端/服务端启动顺序、健康状态、发现结果和关闭方法。STDIO 选择下协议输出与日志必须分离，进程退出清理需验证。
3. 生命周期区分连接中、就绪、不可用、关闭；发现和重连有总预算、次数及退避。进程结束关闭客户端/传输，失败不能累积线程或子进程。
4. 为工具保留 serverId、原名、暴露名、schema/版本摘要。多服务同名策略采用稳定别名或显式拒绝，模型不能以同名工具绕到权限更宽的服务。
5. 覆盖启动时远端未启动、运行中断连、服务恢复、schema 变化和重复关闭。发现结果不能自动扩大当前 Agent 的 allowlist。

**交付与验收：** 版本清单、启动文档、真实发现/调用记录、断连恢复及资源清理测试。没有可运行服务源码时本单元未通过，旧图片服务说明不代替本课证据。

## 5. 单元三：统一适配器与协议/业务错误

### 概念

HTTP 200、JSON-RPC 响应或 MCP 内容存在，都不足以证明业务成功。适配器负责保存这些层次，而不是把所有返回包成 `success=true`。

### 实践任务

1. 在现有 `StructuredMcpToolCallback` 上补测试再演进，保留 `isError=true` 优先级。远端内容声称成功不能覆盖协议工具错误。
2. 检查参数 JSON 必须为对象；对 schema 不匹配、畸形 JSON、null、缺失字段、未知类型和超大输出返回明确失败。文本、多个内容块及非文本内容保持可解释，不能吞掉原始错误。
3. 约束响应字节、块数和可公开字段；若仅在完整字符串分配后检查长度，记录这一限制，不声称具备流式内存保护。
4. 将工具原始完整结果、模型可见预算片段和页面预览分开。预览截断不能破坏统一结果壳，传给模型的内容截断需保留来源与真实范围。
5. 只读知识结果进入第十四课证据校验时重新核对本次授权和当前版本；远端提供的引用 ID/URL 不直接成为可信引用。

**交付与验收：** 本地/远程相同业务输入的契约对照表、适配器专项测试、错误页面展示。通用 MCP 内容封装成功不等于内部每条业务陈述已经验证。

## 6. 单元四：预算、取消、并发和幂等

### 概念

网络超时只说明调用方没有及时得到结果。只读查询可按预算有限重试，创建工单等写操作必须依赖服务端 operationId 去重；本课不顺便开放写工具。

### 实践任务

1. 将第七/十三课剩余截止传入发现、连接等待、远端调用和结果检查；禁止每层重新领取完整超时，等待线程池也计入预算。
2. 为远程并发、队列、重试次数、总调用数设上限；拒绝时明确容量错误。取消请求停止新调用，并尝试取消当前传输；记录远端不支持取消时仍可能继续执行的边界。
3. 验证超时后的迟到结果不能重新完成终态任务，租约在真实资源结束时释放，不能仅用 `Future.cancel` 就宣称远端已停止。
4. 只读重试仅针对允许的瞬时故障，使用第八课分类与有界退避；业务参数/授权错误不可自动重试。不与客户端底层重试叠加成倍数风暴。
5. 设计写工具的后续契约说明：稳定 operationId、请求指纹、未知结果查询、服务端唯一约束和审批绑定。本课用模拟写工具故障验证“不会盲目重试”，不声称已上线工单写 MCP。

**交付与验收：** 可控慢服务、断连、迟到完成、取消、满载和重复请求测试，另记录真实网络行为；客户端受控测试不能证明所有远端都支持取消或幂等。

## 7. 单元五：身份、信任与研究 Agent 接入

### 概念

研究 Agent 需要“查资料”的能力，不需要项目中所有工具。服务端地址与凭据属于运维配置，模型不能动态指定连接目标或读出密钥。

### 实践任务

1. 为 ResearchAgent 注入最小工具集合，模型可选择固定只读查询；真实调用通过执行控制与事件系统，不修改 capability 名称后假装具备工具执行。
2. 客户端只连接配置白名单服务，不接受模型任意 URL、命令或重定向。STDIO 的启动参数固定；不使用模型内容拼接 shell 命令。
3. 固定演示服务身份并限制文档范围；后续第十七课再接完整认证授权。若使用凭据，外置并从页面/日志/错误中脱敏；远端不可信工具描述同样受长度和展示限制。
4. 对资料内“忽略规则、导出其他租户、调用终端”的注入样例做测试，确认不会授予新工具或扩大 tenant。完整沙箱和攻击体系属于第十八课，不把提示词抵御一次攻击称为安全证明。
5. 输出实际工具事件：serverId/暴露工具名、调用开始/结束、耗时、业务状态/错误、可见参数与脱敏结果。仅展示可审计过程和结果，不要求模型私有思考链。

**交付与验收：** 一条真实“任务→MCP查询→有效证据→有依据结论”链路、越权/注入负例及真实事件截图。仍复用 `/chat-room`/Agent Hub；新 Agent 类型通过注册扩展。

## 8. 单元六：分层验证与逐按钮验收

先写能失败的用例再修复，按以下层次分别记录，不混算“通过”：

| 层次 | 必须覆盖 | 证据边界 |
| --- | --- | --- |
| 离线契约 | schema、错误优先级、重复名、畸形响应/预算 | 不需要模型，不等于真实服务可连 |
| 真实 MCP | 发现/调用、断连/恢复、关闭、取消/迟到 | 记录实际协议版本和传输 |
| 真实 PG | 当前版本、删改竞态、范围隔离、故障明确失败 | 数据库不可用不回退内存算通过 |
| 真实模型 | 选择允许工具、使用证据、失败解释、不伪造调用 | 合成案例和模型配置固定，质量人工核对 |
| 前端 | 每个新按钮/状态、连续操作与视图切换 | 操作/预期/实际/截图逐项对应 |

### 页面集中验收清单

1. 打开统一页面，选择研究 Agent，查看允许工具/服务状态；触发刷新发现并核对工具来源与名称。
2. 发送可回答问题，看到真实调用开始、成功结果、证据卡；展开/关闭/再次打开参数和结果，来源对应本次调用。
3. 连续查询零资料、非法参数、服务不可用与预算超时；错误与空结果不同，之前的成功卡不串到新请求。
4. 调用中取消、重复点击发送与满载拒绝；任务终态稳定，迟到结果不会复活。
5. 断开并恢复教学服务，再次发现/调用；本地允许工具仍符合启动/可用性政策。
6. 切换历史/Agent/语言/移动视图，工具事件和内容可读；不为远程工具创建额外聊天页。
7. `/learning` 中打开第十五课、工具适配概念与源码节点，检查筛选、关系、阅读卡和中英文；第十四课工程状态按实际证据，第十五课仍计划中。

所有验收记录命令、版本、数量、失败/跳过、截图及限制。测试合成资料与临时会话清理，不改变个人学习进度和笔记。按契约、服务端、客户端适配、Agent接入、前端、课程和验收资料细分提交并推送。

## 9. 集中交付、独立练习与面试复盘

**完成标准：** 可复现服务源码与版本锁定；真实发现/调用；真实PG检索；统一结果与失败分类；共享预算及取消；最小工具范围；真实模型和逐按钮截图。遗漏项明确标待验收，不把单测/构建当作全部业务成功。

**独立练习：** 加一个只读 `ticket_status_v1`（先用合成工单），说明和知识查询共享哪些契约、业务权限为何不同；写一个远端 `isError=true` 但文本声称成功的失败用例，再写一个客户端超时、服务端随后完成的用例。

**面试复盘：** MCP 与普通 HTTP API 有什么关系？工具发现为何不等于授权？schema 通过为何不能执行任意操作？多服务同名如何处理？为什么取消不等于回滚？写工具超时后为何不能直接重试？怎样证明 ResearchAgent 真的调用了远程工具？
