更新：2026-10-25。长期入口为前端 `/learning`。此表记录**工程和证据**，个人掌握、笔记与阅读进度由本人维护；完成代码、测试或发布学习任务不会自动标记已掌握。

## 长期执行约定

用户已授权按批依次推进剩余课程。当前先完成第十五课，随后顺序实施第十六至二十八课，并补齐第十课 Temporal 对照实验；已有实现先核实、复用和补验，不重做整套。必要的外部依赖不可用时，保留具体未验收项，不以替代品声称原主线成功。

每批完成一个完整功能单元：概念与代码定位 → 子 Agent 实现/补齐 → 失败优先测试及相关回归 → 真实依赖/模型验证 → 前端逐按钮截图 → 发布下一课完整任务 → 同步课程/图谱/边界 → 按职责细分提交并推送。进度持续写入本表和各课实现记录；表中的计划不表示未来课程已经实施。
