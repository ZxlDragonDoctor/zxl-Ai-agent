# 第十八课实现记录

状态为进行中。第一批实现研究回答的证据字段投影，以及本地 HTTP 原文回源的字节上限。

`StreamingResearchModel` 只把当前已复核的知识片段投影到 `EvidenceEnvelope`。服务端生成引用编号、固定来源类型和正文摘要，保留文档、版本、片段及行号。正文按原样序列化为用户数据，回答请求的工具集合为空。远端自报的来源类型、截断标志、租户或政策字段不会进入这个模型输入。课内先比较失败用例和修复后的请求形状，再追踪 `ResearchRunner` 的证据复核和执行授权。[内容来源与权限边界](18-threat-model.md)

`McpEvidenceVerifier` 的本地 HTTP 回源在复制响应字节前累加长度，超过 1 MiB 立即取消订阅。非成功状态、非 identity 编码和不合规的长度声明在接收正文前拒绝。无长度的分块传输也受相同字节上限和原截止时间约束。回归使用本地 HTTP 服务实际发送超限分块并观察断连。正式注入的授权回源适配器走独立路径，仍需针对该路径分别验收。

本批覆盖研究模型证据输入和本地回源两个控制点。知识问答适配器的统一投影、运行环境隔离和真实攻击矩阵继续按第十八课任务推进。[完整任务](18-prompt-injection-and-runtime-isolation.md)

六类 Java 回归共 43 项通过。模型输入用例先复现远端的 `sourceKind=SYSTEM` 被转发，修复后确认固定来源类型、空工具集合和正文原样保留。HTTP 回源用例使用本地服务器。另用真实 PostgreSQL、MCP 和 qwen-plus 复验一次正常 Skill v3。四步完成，草稿只含甲租户引用，持久化为 `completed`。这次正常请求用于验证新版证据格式可以完成原业务。[脱敏正常链路记录](evidence/18-evidence-projection-live-2026-11-09.json) · [页面与图谱截图](../images/lesson18-evidence-boundary-2026-11-09/README.md)

研究工具的事件发布现位于首次原文复核之后。`ResearchRunner` 取得候选命中后先检查当前来源，再通过发布权限门发送 `ResearchToolResult` 的公开字段。工具卡保留经过复核的片段、版本、原文位置和限定的检索诊断，移除远端自由文本、完整响应和未知字段。工具耗时仍只统计工具调用，工具卡成功状态要等来源复核。被拒绝时只发布本地诊断。已经持久化的旧工具事件仍按原会话的授权读取策略处理。

三个定向用例先复现候选提前发布、未知字段外泄和远端错误正文外泄。修复后 44 项 Java 回归通过，其中 2 项连接真实 PostgreSQL。前端 50 项知识测试、37 项图谱测试及构建通过。

真实浏览器运行中，模型选择一次只读 MCP 查询。复核识别合成文档中的已知攻击句式，运行以 `MCP_EVIDENCE_REJECTED` 结束，公开工具卡与持久化历史均没有合成标记，最终回答未调用且未生成草稿。导入阶段早期有一次向量化失败，复跑导入成功。此次实测覆盖一个已知句式，独立留出集和容器隔离仍待验证。[浏览器与图谱截图](../images/lesson18-tool-publication-2026-11-09/README.md)

正常对照首轮在模型选择时发生网络错误。另一次简短请求用原 30 秒预算完成，持久化草稿仅含甲租户引用。工具事件有两个经复核的片段和六条检索阶段诊断。此正向结果来自真实接口及持久化记录。恢复验收会话时，原本地启动脚本和环境文件已缺失，新版正常工具卡的原文按钮仍待截图复验。[脱敏运行记录](evidence/18-tool-publication-live-2026-11-09.json)

知识问答的生成与评判共用的 HTTP 客户端现将响应头和正文放在同一个截止时间内。收到响应头后，若正文停滞，原预算到期时取消 HTTP 交换。实际响应数据在写入缓冲前计数，上限为 64 KiB。正式知识回源客户端已有独立的流式限额，继续走原授权流程。

使用本地 HTTP 服务发送响应头和一个正文字符后暂停，旧实现超过 3 秒仍未退出。修复后，用例在 1 秒请求预算到期后退出。这个用例验证传输行为，真实模型复跑仍待恢复启动配置。

知识问答生成与评判使用请求内证据编号、正文和截断标记。文档与片段 ID、版本、来源名、位置和摘要保留在服务端复核及授权引用中。生成请求的偏好只允许已定义的语言、详略和格式组合。生成契约更新为 `prompt-v3`，评判更新为 `prompt-v2`。本地 HTTP 测试先复现内部字段出现在模型请求中，再验证生成与评判的消息正文符合新契约。21 项 Java 回归通过。正式启动配置仍缺失，本批真实模型复跑待验收。[图谱页面截图](../images/lesson18-answer-input-2026-11-13/README.md)

新增固定文本摘录实验，包含独立镜像、容器启动器和输入输出契约测试。本机 Docker Desktop 启动失败，实际入口已验证拒绝运行。GitHub Actions 的真实 Linux Docker 通过正向摘录、配置检查和容器清理。同一容器观察到仅有回环接口、根文件系统拒绝写入和 cgroup 配额。受控监听器确认隔离容器的连接未到达。合成内存负载触发一次 cgroup OOM 终止。[运行隔离实验](18-runtime-excerpt.md)
