# Browser 风格动态图谱

2026-10-22，按用户选择的 Neo4j Browser 经典节点图改版。参考：[官方 Graph result frame](https://neo4j.com/docs/browser/operations/result-frames/)。展示采用白底、分类彩色圆点、圆内多行标题、细箭头和沿线关系标题。

## 页面操作

前端打开 `/learning`。默认展开当前探索起点的一跳邻居，画布占据主要空间；顶部可打开课程目录/筛选或阅读面板。

| 操作 | 效果 |
| --- | --- |
| 单击节点 | 选中、显示属性与环形菜单，不替换探索起点 |
| 双击节点，或环形菜单 + / − | 展开/收起一层邻居；共享邻居只要仍有可达的展开路径就保留 |
| 环形菜单 ◆ / ○ | 固定/取消固定节点；拖拽后固定状态仍生效 |
| 环形菜单 × | 只从当前画布隐藏，不删除知识数据 |
| 拖动节点 | 临时拉住节点并重新激活力布局，松手自然收敛 |
| 拖动空白处 / 滚轮 | 平移 / 以鼠标位置为锚点缩放 |
| 右侧 +、⊡、− | 放大、适应整个可见图、缩小 |
| 右侧 ↻、⛶ | 恢复隐藏节点并取消固定、重新布局 / 全屏 |
| 单击关系 | 底部查看关系类型和建立关系的理由 |
| 底部“阅读知识” | 打开所选知识的正文、练习、证据和笔记 |
| 以所选为中心 | 把选中节点设为新的探索起点 |

课程目录搜索、实体/阶段/关系筛选、学习进度和导入导出继续可用。环形菜单支持键盘 Enter / Space；减少动态模式计算静态布局，拖拽不启动持续模拟。

## 怎样构建动态效果

1. 知识层：`catalogue.json` 维护节点与有向关系，不保存力布局坐标。
2. 探索层：`graphPresentation.ts / discoverScene` 计算探索起点、跳数与展开分支的可达节点。单击选择和展开分开，收起时重新计算共享可达集合。
3. 布局层：`KnowledgeGraphCanvas.vue` 将节点副本交给 D3 的连接、排斥和碰撞力。原始布局对象保持稳定，tick 时通过 `triggerRef` 通知 Vue，减少代理对象参与物理计算。fx/fy 固定坐标，拖拽改变模拟热度。
4. 几何层：按圆半径截断箭头，对同一对节点的多条关系使用不同曲率；关系标题翻转为可正向阅读的角度。中英文标题在圆内换行。
5. 相机层：画布坐标与屏幕坐标通过 SVG 逆矩阵转换，缩放保持鼠标锚点；适应视图计算可见节点包围盒。

这五层分别处理真实知识、探索范围、坐标、形状和视角。页面的动态效果不依赖 Neo4j 数据库连接。
