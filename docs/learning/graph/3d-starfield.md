## 怎样看和操作

| 操作/显示 | 含义 |
| --- | --- |
| 小圆形亮核与柔和光晕 | 真实课程、阶段、概念、证据和来源；颜色按类型区分，低幅明暗变化不表示执行或掌握程度 |
| 节点大小 | 基于不同邻居数计算，有上限；不表示个人掌握程度 |
| 节点之间的松弛弧线 | catalogue 中已维护的真实关系，流动粒子沿弧线运动 |
| 沿线运动的粒子 | 表达关系方向的视觉效果，不是工具执行事件 |
| 背景星点 | 环境装饰，不是知识实体，不参与图查询 |
| 空白处拖动 / 右键拖动 / 滚轮 | 旋转视角 / 平移 / 缩放 |
| 悬停节点 | 高亮真实邻居及连接，其余网络淡化 |
| 点击节点 | 立即展开并高亮邻域，在节点旁直接打开完整阅读浮窗；保持视角，节点与曲线继续轻微摇曳 |
| 点击关系 | 显示关系类型及建立关系的理由 |
| 拖动阅读窗标题栏 | 调整阅读位置并停留；窗口不会被拖出图外；标题栏方向键也可移动，↺ 回到节点旁 |
| 暂停动态 | 停止闪烁、自动环绕、关系粒子和力布局，仍可手动查看 |
| 全景 / 重排 | 镜头适应所有可见节点 / 再次启动力布局 |
| 标签 / ⛶ | 显示更多文字，仍避免碰撞 / 图与阅读浮窗一起全屏 |
| 2D / 打开知识列表 | 切换备用画布 / 使用可访问目录阅读知识 |

自动环绕在手动操作、悬停和阅读期间让出控制。浮窗可用关闭按钮、Esc 或 3D 空白处关闭；点击关联知识即可切换正文。减少动态模式遵循系统偏好或页面复选框：关闭星光呼吸、自动旋转、粒子及镜头补间，预计算静态布局。3D 容器获得键盘焦点后，左右方向键可切换节点，Enter 打开阅读。

常驻标签使用 11px 普通、12px 强调的原生文字，去掉厚重方框；按投影后的文字矩形避让，普通邻居默认最多五个。完整详情浮窗保留课程正文、工程状态、练习、面试题、路径、笔记和关联知识；锚点定位窗口和引线，相机偏移给阅读留空间，窄屏图内底部阅读。本轮实际验证边界见[交互修正](interaction-clarity.md)。

后续反馈后已移除四角星芒与尺寸呼吸，改用自然圆形光点和低幅、不同相位的亮度变化。点击后所选最亮、直接邻居次亮，其余网络低亮；1/2 跳范围跟随当前所选，无需先点“以所选为中心”。实体与关系筛选仍生效。

2026-10-23 修正点击后静止：移除阅读时的零 tick 和 12 秒停止条件，增加独立的低能量摇曳力。点击给直接邻居一次有界向外速度，弹簧和阻尼带动曲线回落；拖动后重新锚定，避免节点被拉回拖动前位置。阅读浮窗在镜头过渡完成后保持位置，引线继续跟随星点；阅读仅停止自动环绕，不停止节点物理更新。暂停动态或减少动态仍会停止摇曳，页面隐藏/离屏仍暂停绘制。

线条交叉只是显示几何，不是关系端点；3D 中不同深度的线也可能投影到同一点。不能为视觉交叉新增知识节点。页面已增加提示，直接关联仍严格按 catalogue 的边端点决定。

## 从项目学习 3D 图谱开发

- `graph3DModel.ts`：将知识节点复制为带坐标的物理节点，过滤无端点的连接，按唯一邻居计算大小。库会修改节点位置及 link.source/target，所以不能把 catalogue 本体传进去。相机沿当前视线飞近目标，目标与相机重合时使用有限的默认方向。
- `KnowledgeGraph3D.vue`：Three.js 用球体和共享辉光表示节点，CSS2DRenderer 用浏览器原生 HTML 显示清晰标签；WebGLRenderer 与 EffectComposer 同步设备像素比（上限 3）。3d-force-graph 在三维中计算连接与排斥力；关系粒子来自真实边。背景使用单独 Points 对象，不进入知识数据。详细原因见[清晰度修正](interaction-clarity.md)。
- 相机与布局分离：OrbitControls 管理视角；cameraPosition 负责镜头补间。停止动态时仍保留渲染循环以接受手动交互；页面隐藏或离开可视范围才暂停绘制。
- 生命周期：异步加载完成后先检查是否卸载；切换到 2D 时停止绘制并销毁图实例，释放材质、纹理、几何体、WebGL 上下文、观察器和事件监听。ResizeObserver 同步侧栏开合与全屏后的尺寸。初始化或上下文丢失时回退到 2D。
- `LearningGraph.vue`：按需加载 3D 组件，保留课程筛选、探索范围、阅读、笔记与进度。二维和三维共享稳定知识 ID，不共享物理坐标。

## 验证记录与边界

### 2026-10-24：反复点击后只剩连线

根因是对象身份与资源缓存不一致：`createSpatialGraph` 每次创建新的物理节点，`visualFor` 却按知识 ID 复用旧 Three.js Group。当前安装的 `three-forcegraph` 1.43.6 内部 DataBindMapper 按对象引用匹配，先添加新对象、再移除旧对象；同一个 Group 被新旧节点共同使用时，旧节点清理会移除刚添加的星点并释放资源。连线和 CSS 标签由不同路径管理，所以可能仍显示。

修复在数据来源处保持仍可见物理节点的对象身份：更新知识属性与邻居度数，保留有限坐标，始终不把原始 catalogue 对象交给物理引擎。测试先复现旧代码在第一次更新后 `star A was detached`，再修复；增加连续更新、局部/全图切换、节点移除后恢复的真实 Three.js 场景层回归。当前 `npm run test:graph` 共 27 项通过，生产构建通过。

这是无 WebGL 的场景层测试，直接运行实际底层图库，不是浏览器截图或 GPU 视觉验收。本次仍未绕过既有本地页面访问限制。日志在忽略的 `target/star-nodes-red.log`、`star-nodes-green.log` 和 `star-nodes-build.log`。

Node 内置检查共 11 项通过：3D 数据副本与唯一邻居、相机退化坐标、节点大小上限、邻域取景与曲率，以及二维共享分支、单击展开、严格关联、松弛曲线、箭头和文字换行。Vue 类型检查及 Vite 生产构建通过。3D 代码按需分包；浏览器需要 WebGL 支持。
