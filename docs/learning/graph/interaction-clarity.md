# 松弛连线、单击展开与清晰度

2026-10-22，依据真实页面反馈修正二维和三维图谱的交互与可读性。

## 原因与改动

| 页面问题 | 代码原因 | 修正 |
| --- | --- | --- |
| 单条连线绷直 | 2D 控制点在弦中点；3D 未设置曲率 | 2D 按距离加入下垂，近垂直边补侧向弧度；3D 使用稳定曲率和曲线平面，粒子沿弧线运动 |
| 单击没有展开邻居 | select 和 expand 分开，点击只更新 ID | 单击同时打开所选分支，清除该节点的收起状态、恢复被隐藏的直接邻居，保留其他已探索分支 |
| 高亮范围不准确 | 2D 判断是否连接两个邻居，未严格判断边是否经过所选节点 | 统一用 incidentSelection 计算直接关联节点与边；关联边加亮，其余淡化 |
| 3D 聚焦后看不见关系 | 镜头只飞近单个球体 | 根据邻居范围、相机视角和画布比例计算距离，保留邻域在视野中 |
| 文字模糊 | 3D 标签是小型位图，投影缩放后变小；部分界面字号过小 | 改用 CSS2DObject + CSS2DRenderer 绘制原生 HTML 标签，固定可读字号和高对比背景；同步提高界面字号 |
| 高 DPI 画面不够细 | 像素比上限为 2，未随视窗变化刷新 | WebGLRenderer 与 EffectComposer 同步采用当前设备像素比，上限 3；尺寸变化时同步更新 |

这不是仅由显示器分辨率决定的问题。2D 画布本身是 SVG 矢量；3D 几何画面由 WebGL 绘制，标签现在由浏览器文字引擎绘制。提高画布像素数不能替代合适的标签渲染和字号。

## 学习落点

- `graphPresentation.ts`：有下垂的二次曲线；单击展开状态的不可变更新；入边和出边的严格关联集合。
- `graph3DModel.ts`：稳定的三维曲率、容纳邻居的相机位置，支持竖向窄画布。
- `KnowledgeGraphCanvas.vue`：立刻高亮并把视图移向邻域；布局收敛后校正视图，用户手动移动后停止自动校正。
- `KnowledgeGraph3D.vue`：HTML 标签与 WebGL 场景配合，节点首次创建即应用高亮、大小与标签状态。新增邻居获得有限坐标后再聚焦；卸载时移除标签 DOM 与帧回调。
- `LearningGraph.vue`：二维/三维都使用相同的单击展开入口，路由同步不重复触发展开。仍尊重用户显式设置的关系与节点筛选。

曲线表达视觉松弛，不是对真实绳索进行物理仿真。曲率与镜头只改变展示，不能添加或修改知识关系。
