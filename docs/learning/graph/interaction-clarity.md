# 松弛连线、单击展开与清晰度

2026-10-22，依据真实页面反馈修正二维和三维图谱的交互与可读性。

## 原因与改动

| 页面问题 | 代码原因 | 修正 |
| --- | --- | --- |
| 单条连线绷直 | 2D 控制点在弦中点；3D 未设置曲率 | 2D 按距离加入下垂，近垂直边补侧向弧度；3D 使用稳定曲率和曲线平面，粒子沿弧线运动 |
| 单击没有展开邻居 | select 和 expand 分开，点击只更新 ID | 单击同时打开所选分支，清除该节点的收起状态、恢复被隐藏的直接邻居，保留其他已探索分支 |
| 高亮范围不准确 | 2D 判断是否连接两个邻居，未严格判断边是否经过所选节点 | 统一用 incidentSelection 计算直接关联节点与边；关联边加亮，其余淡化 |
| 3D 聚焦后看不见关系 | 镜头只飞近单个球体 | 根据邻居范围、相机视角和画布比例计算距离，保留邻域在视野中 |
| 文字模糊 | 3D 标签是小型位图，投影缩放后变小；部分界面字号过小 | 改用 CSS2DObject + CSS2DRenderer 绘制原生 HTML 标签，固定可读字号和高对比背景；同步提高界面字号 |
| 高 DPI 画面不够细 | 像素比上限为 2，未随视窗变化刷新 | WebGLRenderer 与 EffectComposer 同步采用当前设备像素比，上限 3；尺寸变化时同步更新 |

这不是仅由显示器分辨率决定的问题。2D 画布本身是 SVG 矢量；3D 几何画面由 WebGL 绘制，标签现在由浏览器文字引擎绘制。提高画布像素数不能替代合适的标签渲染和字号。

## 学习落点

- `graphPresentation.ts`：有下垂的二次曲线；单击展开状态的不可变更新；入边和出边的严格关联集合。
- `graph3DModel.ts`：稳定的三维曲率、容纳邻居的相机位置，支持竖向窄画布。
- `KnowledgeGraphCanvas.vue`：立刻高亮并把视图移向邻域；布局收敛后校正视图，用户手动移动后停止自动校正。
- `KnowledgeGraph3D.vue`：HTML 标签与 WebGL 场景配合，节点首次创建即应用高亮、大小与标签状态。新增邻居获得有限坐标后再聚焦；卸载时移除标签 DOM 与帧回调。
- `LearningGraph.vue`：二维/三维都使用相同的单击展开入口，路由同步不重复触发展开。仍尊重用户显式设置的关系与节点筛选。

曲线表达视觉松弛，不是对真实绳索进行物理仿真。曲率与镜头只改变展示，不能添加或修改知识关系。

## 第二轮：星点突出与直接阅读（2026-10-22）

第一轮标签虽然清晰，但 14/16px 的方框文字过重；摘要再跳侧栏的路径也不适合连续学习。本轮将视觉与阅读作为一个完整功能调整：

| 层级/状态 | 当前实现 |
| --- | --- |
| 总览 | 暗背景装饰星，知识节点由白亮核、类型色辉光和四向星芒组成；没有初始整图淡化 |
| 动态 | 每个知识节点使用稳定相位、约 4.5 秒明暗周期；不增加知识实体，不表示工具事件或掌握状态 |
| 标签 | 11px 普通、12px 强调，原生 HTML 保持清晰；移除大方框，按屏幕矩形优先避让，默认最多五个普通邻居标签 |
| 选择 | 星点与直接关联边加亮，其他节点保留较弱光，展开规则保持不变 |
| 阅读 | 单击直接打开完整正文浮窗，保留状态、笔记、源码路径与关系导航；浮窗位于图内，不改变画布宽度 |
| 定位 | 三维组件投影所选坐标，输出锚点；父页面限定浮窗边界并绘制细引线；宽屏相机偏移留出阅读位置，窄屏图内底部阅读 |
| 稳定性 | 阅读时停止自动环绕和物理漂移，保留缓慢星光；关闭后恢复探索；支持关闭按钮、Esc，三维空白处也可关闭 |
| 生命周期 | 复用图引擎的 CSS2DRenderer 渲染回调，锚点限频并去重；继承离屏暂停和销毁清理，释放新增星芒纹理与材质 |
| 减少动态 | 静态星光、无粒子/自动旋转/镜头补间；内容仍可阅读 |

职责划分：`KnowledgeGraph3D.vue` 管渲染、投影、视角和星点层级；`LearningGraph.vue` 管学习选择、上下文浮窗、正文和进度。2D 同样单击打开图内完整阅读窗，当前使用边界内默认位置，不声称它跟随 2D 节点投影。

本轮执行 Vue 类型检查与 Vite 生产构建，均通过；检查本次差异和 JSON 引用。没有新增或运行自动测试，也没有真实模型调用。前述 11 项是上一轮几何与邻域检查的历史结果，不能当作本轮星芒、避让或浮窗的页面测试。浏览器访问限制仍在，本轮没有实际鼠标操作、视觉截图或帧率验收，尚不能宣称视觉效果已在真实页面验收。

## 第三轮：自然光点与明确邻域（2026-10-22）

后续反馈认为四向星芒不符合自然星空，本轮移除了该形状及其纹理、材质和逐帧缩放。知识节点现在只有小圆形亮核和径向柔光，光晕以两条低幅、不同频率的正弦叠加改变亮度，尺寸保持不变；减少动态时亮度固定。背景装饰星也使用圆形透明纹理，避免默认方形点。

选择状态直接来自父组件的 `selectedId` 与阅读状态，不再以另一份内部 focus 值决定高亮。选中节点最大最亮，直接邻居适度放大、保留偏白的类型色与明显光晕，其他节点低亮；只有直接相连的边加亮，推荐路径不会抢占选择的视觉焦点。悬停不会替换正在阅读的选择。

1/2 跳按钮每次按当前所选重置中心，即使重复点击同一按钮也能重置探索范围；局部视图内点击新节点会以新节点为中心展示邻域。仍保留用户的实体和关系筛选，不把不存在的知识关系画出来。

本轮仅执行前端类型检查、生产构建和差异检查，没有新增或运行自动测试。实际页面视觉、鼠标交互与 GPU 帧率仍未完成验收。

## 阅读窗口拖动（2026-10-22）

阅读浮窗支持拖动标题栏，使用 Pointer Capture 在指针离开标题栏后仍连续接收移动；抬起、取消和丢失捕获时结束拖动。鼠标与触摸共用 Pointer Events，不注册额外全局拖动监听。

手动位置优先于自动节点锚点，拖动后窗口停留在用户选定处；切换知识或关闭窗口后重置，点击“回到节点旁”也可恢复自动定位。移动始终限制在图内，缩放/窗口尺寸变化后重新约束边界。标题栏可用 Tab 聚焦，再用方向键每次移动 20px；正文滚动、选字、按钮点击保持原功能。

本轮执行类型检查与前端构建，不新增或运行自动测试；受已有页面访问限制，实际鼠标/触摸/键盘体验尚未人工验收。

## 连续摇曳与点击弹性（2026-10-23）

用户反馈 3D 点击后静止、缺少 2D 的灵活反馈。源码根因有三项：阅读时设置 `cooldownTicks(0)`；即使 tick 上限无限，`cooldownTime(12000)` 仍会先结束布局；布局 alpha 冷却后，没有持续驱动力，只剩光晕明暗和关系粒子。

当前取消前两个自动停止条件，设置 alpha 下限为 0，让动态模式持续接收 tick。新增 `graph3DMotion.ts`，以每节点的稳定相位、局部休止点、有限加速度和低幅周期目标驱动三轴摇曳；热布局阶段跟随布局更新休止点，冷却后围绕局部位置摆动。选中节点幅度更小、直接邻居更明显，点击附加一次有界向外速度，通过已有连线弹簧和阻尼回落。坐标更新发生在物理副本上，所以关系曲线随端点运动，知识实体与边没有改变。

初次打开仍预计算布局；后续展开保留可见的弹性收敛过程。拖动节点时让出固定坐标，松开后重新锚定。没有增加额外动画计时器；复用图引擎 tick，离屏暂停，减少动态/手动暂停关闭驱动力。自动镜头环绕和节点摇曳独立：阅读只保持镜头，不冻结节点。

阅读窗口在初始 850ms 镜头过渡后锁定自动落点，避免跟着星点摆动；引线仍实时指向所选星点。手动拖动、回位与调整窗口尺寸保留原行为。

连线的二维交叉或三维投影交叉不产生连接；只有边的 `from/to` 定义知识关系。为交叉补点会伪造知识，当前通过页面提示与严格邻域高亮解释这一点。

本轮执行 Vue 类型检查、前端生产构建和图谱载入校验，不新增或运行自动测试；页面访问限制仍在，没有完成实际 GPU 动效、手感和帧率验收。
