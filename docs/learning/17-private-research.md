# 第十七课：把研究 Agent 接入可信运行

## 从工具调用走到企业执行

研究不只是调用模型：它需要选择只读工具、查询当前知识、复核原文、带引用回答。每一步还必须属于同一用户和运行。Task 输入只表达问题与依赖，可信身份、权限和取消对象由 Java 显式传递。

## 本次落地

`ResearchAgent.processTask` 捕获 ExecutionScope 后进入工作线程。scoped 任务只从 TrustedRunContext 取 ActorRef/runId，调用 ScopedResearchFactory 四参接口，并由 Java 补充 run.readOwn。工厂固定加入 agent.execute 与 knowledge.read；MCP v2 请求及原文复核继续携带同一身份、附加权限和运行 ID。没有上下文或工厂即拒绝，不会走旧 v1 ResearchRunner。

四参接口另接 Java 控制边界：实际模型订阅遵循“当前授权事务 → 短 ExecutionControl.admit → 启动订阅”，取消/预算可以阻止尚未获准的订阅，等待响应位于锁外。旧工厂接口保留兼容，默认 admission 不含运行取消控制，正式多 Agent 不应使用它。

两次研究模型请求仍经过原执行器容量与记账，使用同一捕获 scope；正式成功用例记录2次模型调用。模型工具参数没有身份字段，也不能选择运行权限。

## 事件与完成状态

scoped 工作任务的开始、完成、失败、取消和工具事件进入所属运行的 PrivateRunEvents，不经过全局 AgentMessageBus；事件 executionId 由可信上下文覆盖写入，工具事件内也绑定该 runId。

工具事件由 ResearchRunner 自己的完整授权 gate 包裹，回调只做短控制准入与本地入队，避免在一个 PG gate 内再开同主体的第二个 PG gate。任务完成则在运行发布 gate 内转换 TaskLifecycle，再入队。私有通道类型禁止任意观察者回调，避免发布回调异常发生在不可逆的 COMPLETED 之后。

**运行入口必须把研究的完整权限集合加入运行边界**，包含 agent.execute、knowledge.read、run.readOwn，才能在最终任务完成时再次阻止知识权限撤销。工厂内部的独立校验不能替代这项入口要求。正式 submit/状态/取消入口及编排报告隔离仍待实现，不能开放旧全局报告作为替代。

## 分层证据

- 自动化11类90项通过，包含上下文/队列8项、研究工作 Agent5项、研究工厂/协议9项，以及任务完成、编排与模型边界相关回归。不是90个全新用例，也不与历史通过数量简单累加。
- 工作 Agent测试覆盖正式工厂选择、无工厂拒绝、私有通道、完成前撤权、工具返回后撤权及取消后禁止发布/汇总。工厂准入用例先失败，再验证取消在授权 gate 内发生时订阅动作0次。
- 真实PG2项通过：实际运行 owner 才能启动，其他租户不能产生私有事件/模型工作；回答阶段撤销真实membership后不完成任务，PG保留拒绝审计。测试只创建随机合成账号，finally清理并关闭连接池。
- [精确范围和失败记录](evidence/17-private-research-tests-2026-11-06.json)。首次回归遭遇旧编译类与新队列返回类型不匹配（NoSuchMethodError）；仅清理本批两个生成类后重编译，重新运行完整选择范围通过，保留原失败日志。

上述PG用例的模型、MCP响应和知识正文均为确定性替身；后续真实链路补测见下节，两类证据不能混用。运行中的旧 JVM 不会因为编译而更新。前端只同步知识与边界，正式研究编排页面还没有可用的新入口。第十七课保持进行中，下一课任务仍是第十八课提示注入防护与运行隔离。

## 后续真实研究链路补测

使用当前编译代码直接创建可信 ResearchAgent，连接实际本机PG授权、18135 MCP、18132知识worker及qwen-plus，预算固定30秒。两个已有合成测试账号分别创建独立临时运行owner，任务通过真实v2检索与原文复核；测试结束只撤销本次会话并清理本次运行owner/审计，没有修改知识文档或个人学习进度。

- [首轮记录](evidence/17-trusted-research-live-initial-2026-11-06.json)：乙任务COMPLETED、模型调用2次、工具完成，回答含乙标记而无甲标记，引用存在，5条私有事件均绑定本运行。甲首轮FAILED，仅记录1次模型调用；当时未采集细分错误码，根因未确认，不能把复验成功写成原失败已定位修复。乙的30089ms字段包含会话清理等待，不能视为精确执行耗时。
- [甲独立复验](evidence/17-trusted-research-live-retry-a-2026-11-06.json)：保持同代码、同预算，任务21078ms完成，模型调用2次、真实工具完成，回答只含甲标记及引用，5条事件均绑定本运行。复验成功不证明多轮稳定性。

这是直接可信工作Agent的实际执行，不经过尚未实现的正式编排HTTP入口，不能当作完整多Agent业务页面验收；新scope代码没有通过重启自动替换原服务中的旧对象。
