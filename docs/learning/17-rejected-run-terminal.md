# 第十七课：撤权后的运行收尾

运行已经取得许可并保存了启动记录。执行过程中，用户在另一个浏览器上下文退出同一会话。后续工具结果要再次通过权限检查。权限失效时，服务端拒绝发布结果和保存执行内容。

修复前，失败收尾又依赖同一个已失效的会话。浏览器退出成功，授权审计有拒绝，但本地记录在 35 秒后仍是「执行中」。下次授权读取可以把遗留记录标成中断，这会丢掉权限检查失败的原因。

`AgentConversationService` 现在区分结果保存和运行收尾。结果保存继续经过 `RESULT_PERSIST`。权限门拒绝后，持有本次会话执行租约的服务端回调只会结束自己已创建且仍在运行的记录。写入固定错误、结束时间及空答案和空事件，不接收请求方提交的收尾数据。历史读取继续依赖当前授权。

真实复验在 Skill v3 发出只读工具请求后退出。退出返回 HTTP 204，真实 PostgreSQL 审计记录 `RESULT_PUBLISH` 和 `RESULT_PERSIST` 的 `UNAUTHENTICATED`。重新登录前已观察到终态。重新登录打开同一会话，页面显示权限无法确认，没有草稿。读取历史不触发模型复跑。

练习时从完成回调追到权限门和执行租约。说明为何可以保留一个固定失败状态，哪些信息不能由此写入历史，以及为什么外部工具能否回滚需要工具自己的契约来保证。
